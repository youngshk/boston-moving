- **사인업 보너스:** 현재 없음 (전화 확인 권장)

- **유틸:** 난방·쓰레기 포함 (이 그룹 중 유일)

- **기타:** 24/7 컨시어지, 피트니스+요가, 히티드 솔트워터 야외 풀, 온사이트 데이케어, 9ft 천장
